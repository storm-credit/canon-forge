## §2 불가침 좌표 (뼈대 설계 시 이동 금지)

- **FS-0001 체인**: 14(재관측)·16(협곡 요동)·40("나는 왜 저 방향을 알고 있지?" — A3 결착 앵커)·100(나침반+견인 잔파편 첫 상호 공명)
- **FS-0003 = 88화** "너 방금, 그 이름 부르는 데 반 박자 늦었어" (정밀 구현 — 다운스케일만)
- **FS-0004 씨앗 = 99화** "성국이 무서워하는 건 우리가 아니야, 우리가 '본 것'이지" (정식 설치는 1-B 유예)
- **26화 루미에 호명 앵커** (※융합 서사와 얽혀 있음 — §4-① 판정에 종속) → **✅ 종속 해소(2026-07-28)**: §4-① (a)안 확정으로 **앵커 존치**. 단 26화는 **이름 공개 앵커까지만** 유지하고, 파편 연결은 **암시 수위**로만 얹는다(명시 공개는 후반 이연 — §4-① 조건 4-①).
- **카르델라 아크 55~58 박제** (지적장부·A5 확정)
- **100화 이중 결말**: 살생부+지도 조각=서랍 이중 바닥 은닉 / 지하 견인 vs 성국 방향 미확정 / 무소속·얼굴 없는 전설 → 1-B 인계
- 봉인: 감시자 무명(60·73·76~77 흔적만 — 구판 준수 확인)·FS-0002 여백 유지·240 다리우스

## §3 신판 훅 ↔ 구판 자산 접속점 (8)

1. **기억 소거 미스터리**(신판 6화) ↔ 17~18 실종자 명단·이름 두 번 지워짐 + 44~46 '23회 발자국' 기억소거 존재 + 62 방명록 이름 소거 — 같은 주제 3자산을 한 인과선으로 통합(1장 세로축 승격 후보)
2. **환영의 서 종이**(신판 1·8화) ↔ 11화 라인하르트 첫 가동 + 50~52 성국의 실명 호명 + 91화 재사용 — 페르소나 캐논 정확 일치, 무수정 접합
3. **카르델라 표식**(신판 10화) ↔ 53~54 저울 문양+평의회 인장 병치 + 98화 검은 정장 접선 + 28~29 '인장' 모티브 — 명칭 통일로 신구 접합
4. **다섯째 쪽지=지켜보던 손**(신판 10화) ↔ 이름 없는 소환사(56~64) 또는 성국 회수조(51) 재해석 — 신규 세력 발명 없이 회수 가능
5. **초소 문·보류 판정**(신판 7화) ↔ 41~49 유적·제단(사람을 고르는 문과 동계 현상으로 정합 가능)
6. **세 손 고정 재배선**: 구판 13·20·56·63~64 카운트 확대분을 전부 '세 손 산하/하청/관찰 대상'으로 재수렴(신판 확립 패턴)
7. **속삭이는 협곡 3중 소문**(16화) — 복선 심기 기법 자체를 신판 표준으로 승격
8. **말바·도렌 등 신판 기명 15인** — 구판 등장 좌표(향신료 노파 92~93 등)와 역할 연결 시 신판 트랙 이름 사용
