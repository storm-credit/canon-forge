# 🎲 아크 A5 「판 위의 이름」 (53~66화 · 14화)

## §0 설계 요지 — 왜 이 아크는 '이름'인가

A5는 **주제 한 줄이 아크 전체를 관통하는 첫 구간**이다. 카르델라는 사람에게 번호를 매겨 장부에 올리고, 판돈으로 이름을 걸고, 값을 치르면 이름을 지워 주는 도시다. 그래서 이 도시의 문법이 그대로 1장 세로축(**기억 소거 = 이름이 지워지는 일**)의 회색 거울이 된다.

| 단계 | 화 | 이름에 일어나는 일 |
|:-:|:-:|---|
| 등록 | 53~54 | 이름이 **번호**가 된다 (중재의 탑 등록) |
| 저당 | 55~58 | 이름이 **판돈**이 된다 (박제 좌표) |
| 회수 | 59~61 | 이름을 **값 치르고 되산다** |
| 소거 | 62 | 이름이 **묻지도 않고 지워진다** (방명록 — 세로축 **인과 확정** 좌표) |
| 결번 | 63~65 | 이름 없는 자가 **장부에서 결번 처리된다** (65 사망 언급 대체 사건) |
| 재정의 | 66 | 이름값을 **스스로 매긴다** — "누구 편도 아닌 값" |

> ⚠️ **아크 A5는 '관찰' 아크다.** 정면 충돌은 A7로 유보(콘티 §3 R2-5 준수). 소환은 **판을 뒤엎는 카드**로 쓰지 않는다 — 그 카드의 무게는 A8에 남긴다. A5의 소환은 전부 **절제 소환(일부만 빌리기)** 수준으로만 쓰이며, 그마저 카지노 규칙상 발각되면 사형이라는 압력 아래 놓인다.

### 세 손 재수렴 설계 (하드 제약 — count 고정)

구판이 흘린 "넷째 깃발"(56화)·"다섯 번째 손"(63화)은 **새 세력이 아니라 미끼 → 회수 구조**로 재배선한다. 세력 count는 신판 010 정본 3손에서 한 발도 늘지 않는다.

| 신판 010 세 손 | A5에서의 얼굴 | 등장 화 |
|---|---|---|
| **죽이려는 손** | **성국 사제 차림 2인** — 51화 성국 회수 장부 등재를 타고 온 **하청 경로**(A7 84화 '성국 장부 하청'과 한 실). 거래의 말투를 쓰지만 하는 일은 **지우는 일**이다("명단에서 지워 드리죠") | 60(말미 예고)·61 |
| **사들이려는 손** | ①**표식으로** 존재 — 팔각 테두리·뒷면 번호 각인 = 신판 010 브란트 쇠 표식과 같은 손버릇 ②**'말끔한 얼굴'**(신판 4화 무명 별칭·20·38화 매입 대리인)이 얼굴로 재등장 — 값만 부르고 이름은 안 준다 | 53·54(표식 회수)·60(얼굴) |
| **지켜보던 손** | **이름 없는 소환사 = 하청**(본체 아님). 010 문틈 쪽지의 늙은 필체가 상부 | 55~64 |
| ※ 카르델라 자체 | **손이 아니라 판** — 블랙 수트·평의회·중재자 길드는 세 손이 마주 앉는 탁자다 | 전 구간 |

- **56화 오독 → 64화 회수**: 에반은 이름 없는 소환사를 잠정적으로 "넷째 깃발"이라 셈판에 올린다. 64화에서 그가 남긴 인장의 각인 손버릇이 010 문틈 쪽지 필체와 같은 손임을 감정해내며, **깃발이 하나 늘어난 게 아니라 손 하나에 손가락이 있었을 뿐**이라는 정정으로 닫는다. 카운트 인플레를 **의도된 오독의 반전 훅**으로 전환.
- "다섯 번째 손"(구판 63화) → **폐기**. 대체 문장은 "세 번째 손이 처음으로 얼굴을 보였다".
- **표식 귀속 하드룰**: 팔각 테두리 + 뒷면 번호 각인 = **사들이려는 손** 전 구간 통일(A2·A4·A7·A8 동일). 죽이려는 손은 **별도 표지**(성국 장부 경로)로만 식별한다. 53·54의 표식 회수 비트는 전부 사들이려는 손 귀속으로 읽힌다.

### 조각 count (하드 제약 — 전 구간 고정 2)

- **A5 진입 시 소지 = 나침반 1 + 견인 잔파편 1(50화 획득) = 누적 둘.** 구판의 "여덟 개"는 전 구간에서 **둘**로 하향 동기화한다.
- 다크 미러의 경고 원문 조정: ~~"여덟 개면— 이미 늦었을지도 모르겠습니다"~~ → **"둘이면— 이미 늦었을지도 모르겠습니다."** / 루미에 되받음: *'둘인 걸 어떻게 알아.'*
- 🔒 **숫자 하드 앵커**: A5 진입·63화 다크 미러 대사·A6 감찰관 "둘" — 전부 **2**로 확정(A4 종속 해소). 51화 제단의 다른 조각은 **성국 압수 = 미획득**이므로 셈에 넣지 않는다.
- A5에서 **새 잔파편은 획득하지 않는다**(1장 내 신규 획득 추가 금지 — 여유 1칸은 2장 이월). 이 아크의 보상은 물건이 아니라 **판의 지도**다.

### 루미에 발화 커브 (A4 만담 해금 이후 · A6~A8 구판 수위 직전)

A5는 만담이 열려 있으나 구판 수위보다 반 단계 아래. 티키타카는 **1~2어절 주고받기**로 속도를 내되, 60·63~64의 존재론적 동요(“파편이 말을 멈춘다”)에서만 문장이 길어진다. 11화 첫 완전 발화(R6-1) 이후의 점증 곡선에서, A5는 **"루미에가 처음으로 자기 소멸을 두려워하는 구간"**으로 배치한다.

### 감시자 흔적 (최종 확정 — 전 구간 4좌표 한정 · A5 담당분 = 60화 1건)

**2026-07-28 작가 확정**: 감시자의 흔적이 놓이는 좌표는 **60 · 73 · 76~77 네 곳뿐**이다. 그 밖의 어떤 화에도 감시자 흔적을 두지 않는다(A4 44~46 '세는 소리'·A6 75 '문턱 냉기'·A7 84·89는 전부 **다른 귀속**). 따라서 **60화는 전 구간 최초 흔적 좌표**이며, 본 아크가 이 4좌표 중 하나를 실제로 **구현**해야 한다.

| 항목 | A5 60화 구현 규격 |
|---|---|
| 매개 | **서신·무기척 계열**(60화 사건①의 서신 전달 동선에 부착) — 사물·온도·자국 같은 즉물 표지만 |
| 수위 | **성질만**. 형체·얼굴·움직임·의도 서술 0. 정면 노출 0 |
| 명명 | **무명**. '감시자'·'지켜보는 것'·'그것' 류의 지시어조차 서술이 부여하지 않는다. FS-0002 여백 유지 |
| 귀속 | **세 손 어느 쪽에도 붙이지 않는다.** 60화가 같은 화에서 사들이려는 손(말끔한 얼굴)의 자취를 이미 보여 주므로, 그 자취와 **결이 다르다**는 대조로만 존재를 세운다 |
| 루미에 | 읽지 못한다. 단 **"못 읽겠어" 계열 대사는 쓰지 않는다**(77화 박제 대사 보호) — 반응은 침묵·회피로만 |
| 에반 | 셈하려다 셈이 안 서서 그냥 덮는다. 결론·가설·연결 서술 0 |

### 루미에르 파편 암시 (조건 4 — 명시 공개 금지)

A5의 암시 수위는 **딱 한 컷**(수위 불변). 단 **연출 매개만 정정** — 루미에르는 A3 결착 이후 **동행이 아니라 원격 연결**(서신·도표)이므로 A5에 몸으로 등장하지 않는다. 55화, 루미에가 복도의 인영을 보고 떨다가, **루미에르가 보낸 서신을 방에서 펼치는 순간 말을 딱 멈춘다**(봉랍을 뜯는 소리 한 번, 그리고 침묵). 에반은 긴장 탓으로 읽고 넘어간다 — 독자만 걸리는 극적 아이러니(요타 §1 축6 최강 지속 장치). 그 외 파편 연결 서술·"같은 조각" 계열 문장 **전면 금지**. ※A5는 루미에르 재투입 아크가 아니다(재투입 = A6 1화·A7 1화·A8 1비트).
