# 아크 A6 「두 명의 에반」 (67~80화) — 신판 화별 뼈대

> **아크명 주의**: PM 배치 지시서 표기는 「매 문양 초대장」이나, 콘티 정본 아크명은 **「두 명의 에반」**이다. 지시서 표기는 *개시 트리거(문서 한 장 = 매 문양 초대장)* 기준 별칭으로 보고 정본명을 유지했다. → **[작가 확인] 아크명 택1**.

## §0 아크 요약

| 항목 | 값 |
|---|---|
| 무대 | 골든마르크(대경매장 부속 연회장·지하 빈민가 거점) → 국경 가도 → 포지게이트 성문 앞 |
| 한 목표 | 성국 사냥개의 눈을 흐릴 **알리바이(2층 분신)를 완성**하고 국경에 선다 |
| 압박 축 | **신원 노출 위험 단일**(51화 성국 회수 장부에 라인하르트 라인 등재 → 성국 추적 진행형). **부채 시계는 16화 완제로 소멸 — A6 전 구간 부채 언급 금지**(상태표 1) |
| 소지 조각 | 나침반 1 + 견인 잔파편 1 = **누적 2**(상태표 3). **A6 신규 획득 0** |
| 개시 트리거 | **외부에서 온 문서 한 장** = 매 문양 밀랍 봉인 초대장(요타 이식 2 — 개시에 1화 초과 금지) |
| 대형 보상 | 2층 분신 기믹 확립 = 인간 세력 상대 무적 알리바이(73화 절정) |
| 대형 여백 | 감시자 비대칭 — "단 한 번도 속지 않은 것"(FS-0002 **씨앗만**, 정면 금지·무명) |
| 결착 상태 | 하나를 **완성**하고 하나를 **봉인**한 채 심판의 문에 든다 |
| 훅 재료 단계 | 61~100 구간 = **정보 공백형 우세 유지**(6) / 위기 임박형(5) / 감정·허탈형(3). **상태표 8 이행 — 정보 공백형 최장 2연속**(구 v1의 73~79 7연속 해체) |
| 루미에르 | **부재 구간 아님** — 원격 연결(서신·도표) **1화 재투입(78화)**. 재회·동행 없음, **파편 암시 수위 0**(조건 4) |
