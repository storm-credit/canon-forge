# 🗺️ 아크 A4 「속삭이는 협곡」 — 31~52화 화별 뼈대 v1

## §0 아크 계약 (설계 헌장)

| 항목 | 확정 |
|---|---|
| **진입** | 31화 = **재착지 아님**. 아크브릿지에는 이미 22화부터 체류 중이며, 31화는 **하부 심부(협곡 방면) 첫 진입**이다. 착지 **로테이션 (b) 산책형**은 이 '심부 첫 진입'에 전용(하강 도르래 삯·발굴품 감정 시세·심부 통행 기록대를 배경 산책으로 흘려 시스템 노출). 아크 내 2차 진입(41화 유적)은 **(a) 문화충격 개그**로 교차 — A3 22(a)·24(c) → 31(b) → 41(a), 동일 유형 연속 없음 |
| **이음매(진입)** | **30화 두 번째 쪽지** 『값은 잘 매겼네. 이제 자네 차례일세.』 → **31화 도입이 콜백으로 받는다**(방치·시간 점프 금지). 미해결 상태로 52화까지 끌고 간다 |
| **결착** | 52화 — 귀환·회복 화 1개 + **문서 한 장(카르델라 소환장)으로 다음 아크 강제 개시** → **53화 도입이 이 소환장을 콜백으로 받는다**(A5 인계) |
| **훅 재료** | 31~40 = 액션·감정의 잔열 → **41~52 = 정체·관계 재정의로 전환**(요타 축2 중반 단계). 화 자기완결 금지, 컷은 언제나 '답 한 발 앞' |
| **불가침** | **40화 앵커 고정** — 루미에 *"…나는 왜 저 방향을 알고 있지?"* (화번호 이동 금지) |
| **잔파편 회계** | 본 아크 **정식 획득 1개**(50화 견인 잔파편) + **목격·미획득 1개**(51화 성국 회수조가 봉인 회수). 1장 누적 = **2개**(A1 나침반 + A4 견인) — 작가 확정 ② 상한 2~3 내, **여유 1칸은 2장으로 이월**(1장 내 신규 획득 추가 **금지** — A5~A8 조각 증가 0). 구판 4~8번째 조각(다섯째·일곱 조각·여덟 조각)은 전부 **일반 주술구 매개체로 격하**(코트 안감 100여 개 중 일부, 잔파편 아님) |
| **세력 count** | **세 손 고정**. 본 아크 신규 세력 0. 아크브릿지 현지 추격자는 **죽이려는 손의 하청**으로 귀속(확대 아님). 성국 회수조는 기존 성국 자산. '23회 존재'는 세력이 아니라 **세로축 현상**(무명·미규정) |
| **루미에 발화** | A4 = **만담 단계 해금 아크**. 기본 문형은 **2인 만담** — 도발자(루미에) / 당하다 가끔 반격하는 화자(에반). 제3의 목소리(루미에르)는 **도표 여백의 주석·회신 한 줄**로만 끼어든다(지면 만담). **실시간 트리오는 40화 재회 1회에서만 성립**(해금 시연). 단 신비·제단·세로축 국면에서는 즉시 톤 하강(요타 이중층) |
| **루미에르 운용(하드룰)** | **동행 아님**(A3 30화 결착 계승). 본 아크 전 구간 **원격 연결** — 그녀는 외지 의뢰로 공방을 비웠고, 왕래는 **도표·서신 회신**으로만 한다. **대면은 40화 단 1회**(파훼 장치·협곡 도표 인계 + 선 긋기). **41~51 유적 구간에 그녀는 없다 — 동행하는 것은 그녀의 도구뿐**(43·48·49의 계측기·파훼 장치는 전부 "맡긴 것"으로 서술) |
| **압박 축** | **부채 시계 금지**(16화 완제 — 본 아크 전 구간 언급 0). 대체 압박 = **신원 노출**: 심부 통행 기록대에 적은 라인하르트 이름(31) → 이름을 아는 손의 값 부르기(38) → **51화 성국 회수 장부 등재**(A7로 인계) |
| **정보 경로** | **도렌 좌판 의존 0**(도렌은 베르나 소재 — 본 아크 미등장). 아크브릿지 정보원 4갈래로 분산: 발굴단 십장·장비 노점·아카데미 서기·**루미에르(도표·서신 원격 회신 — 대면 1회)** |
| **낙차 하드룰** | 신비·폭로 직후 개그 컷 1개 의무 / 무거움 2화 초과 금지 → **41화·47화·52화가 지정 이완 지점**(40·46·51의 무게를 즉시 받아낸다). 유머 삽화 0.5화 상한, 동일 개그 3회 금지 |
| **진동** | 약천마 진동(결핍→작은 돌파→다음 결핍) **화당 1회** — 아래 표 「대가·진동」 열이 화별 배정 |
| **준비 구간 압축** | 31~40을 준비 10화로 쓰지 않는다. **순수 준비 성격은 4화(31·32·35·36)**, **촉매 개선 절차는 2회(32 1차 / 35 2차)**로 통합(구 32·33·35 3연속 폐기). 남는 2칸은 **세 손 그림자 강화·사건 선행**(33 하청 노크 전진 배치 / 34 두 갈래 손버릇 판별)으로 전환 |

## §2 아크 운용 노트

### 2-1. 세 손 배치 (구판 '세 손 스레드 0회' 교정)
| 손 | 화 | 노출 형태 | 확대 방지 장치 |
|---|:--:|---|---|
| 죽이려는 손 | **33~34** | 현지 고용 두건 사내(하청) + **별도 표지** | 대사로 "직접 온 게 아니다" 명시 — 신규 세력 아님 |
| 사들이려는 손 | **38** | **'말끔한 얼굴'**(신판 4화 무명 별칭·A2 20화 대리인과 동일인) + 팔각 테두리·번호 각인 서식 | 신규 인물 발명 0 — **기존 무명 별칭 승격**으로만 처리. 아크당 최대 1회 노출, 이름은 끝까지 안 준다 |

> **표식 귀속 하드룰(전 구간 통일)**: **팔각 테두리 + 뒷면 번호 각인 = 사들이려는 손**(신판 010 브란트 쇠 표식과 같은 손버릇). 죽이려는 손은 **별도 표지**로만 식별하며 번호 각인을 쓰지 않는다. 34화가 이 두 갈래를 처음 분리하고, 38화가 번호 쪽에 얼굴을 붙인다. A2·A5·A7·A8과 동일 규칙.
>
> **'말끔한 얼굴' 승격 노트**: 1장 준-빌런 얼굴 = 사들이려는 손의 **반복 실무자**. 좌표 = A2 20화 → **A4 38화** → A5 60화 → A8 98화. 무명 별칭 유지·관계만 축적하고 정체·소속은 1장 내 미공개.

### 2-2. 세로축(기억 소거) 2차 담당 구간
- 1차(11~30 실종자 명단·이름 두 번 지워짐) → **36화 재확인 + 수첩 필사** → **44화 숫자 대조(23 > 붉은 줄)** → **45화 성질 관측** → **46화 = 존재 확인 + 공포까지만**.
- ⛔ **본 아크 인과 확정 금지(하드 제약)**: "기억 소거는 명단보다 **먼저** 작동한다"는 결론, 그리고 "6화 말바 실종과 **같은 손**"이라는 귀속은 **44~46에서 내리지 않는다**. 44~46이 다루는 것은 **셈이 안 맞는다는 사실 + 그 사실이 주는 공포**뿐이며, 에반은 가설을 세우다 스스로 지운다.
- **인과 확정 좌표 = 62화 방명록**(A5). 본 아크가 62화로 넘기는 것은 결론이 아니라 **재료 3개**: ①23이라는 숫자 ②명단보다 큰 숫자라는 불일치 ③되풀이·세는 성질. 46화 인계 명제도 단정형이 아니라 의문형으로 남긴다 — *"이름이 지워지는 데에 순서가 있다면, 그 순서는 누가 적는가."*
- 이후 계단: 62(인과 확정) → 75~76(새 정보 1개 — '고른 실종'의 선별 기준 냄새) → 99~100(회수 2겹 · 손의 정체는 미공개 유지).
- **[A2/A3 인계 확인]** 실종자 명단 게시 도시가 골든마르크로 재배치될 경우, 36화는 "다른 도시에서 본 것과 같은 필적·같은 두 줄"로 1줄 조정만 하면 성립하도록 설계했다(도시 종속 없음).

### 2-2b. 감시자 분리 (오독 방지 하드룰)
- **본 아크에 감시자의 흔적은 0이다.** 45화의 *"뭔가를 세는 소리"*, 44화의 스물세 발자국, 46화의 획 자국은 전부 **'23회 발자국' 존재 자체의 성질**로 귀속한다 — 되풀이하고, 세고, 돌아나가지 않는다.
- **감시자 흔적 좌표는 60·73·76~77 전용**. 본 아크 산문에서 45화의 소리를 감시자로 읽히게 하는 연결 문구(같은 기척·같은 결·전에 그 자리에 있던 것 등)를 **일절 쓰지 않는다**.
- 46화가 10화 쪽지 필적과 대조해 **"다르다"**로 닫는 것도 같은 목적이다 — 세 손과도, 감시자와도 **별개의 결**임만 확정하고 정체는 무명으로 남긴다.

### 2-2c. 루미에르 원격 연결 운용 (A3 30화 결착 계승)
- **전제**: 30화에서 그녀는 *동행이 아니라 연결*로 남았다. 본 아크는 그 결착을 **문자 그대로** 이행한다 — 같은 도시에 있어도 같은 자리에 있지 않다(외지 의뢰로 공방 부재).
- **접촉 채널 3종**: ①도표·도해 왕복(32·35·39) ②회신 여백의 한 줄 주석 = 제3의 목소리 ③아카데미 서기 편 전언.
- **대면 1회 = 40화**. 파훼 장치와 협곡 도표를 직접 건네고 선을 긋는다. 이 화에서만 실시간 트리오 만담이 성립한다.
- **41~51 유적 구간에 그녀는 없다.** 43(계측기 무용지물)·48(파훼 장치 아군 화력)·49(바늘 튐)는 전부 **"맡긴 도구"**로 서술 — 사람이 아니라 도구가 동행한다. 이 배치가 48화 '관계 재정의'를 **부재중 공조**로 바꾸고, 49화 파편 암시 2를 **대면 없이** 성립시킨다(계측기 파형 ↔ 40화 도표 귀퉁이 손 떨림 표본의 일치, 에반은 대조하지 않음).
- **후속 배정**: A5 결번 없음 / **A6 1화·A7 1화 재투입**(원격 지원·서신·도구 · 파편 암시 수위 0) / A8 98~100 중 1비트 재등장 허용. → 다음 아크 계약에 인계.

### 2-4. 절제 소환 습득 설계 (작가 확정 ④)
- **좌표**: **습득 = 51화(본 아크 단독 좌표)**. 이후 계단은 A5 53·57 실전 → A6·A7은 **재사용(숙련 상승만)**이며, A7 83화는 *"A4 습득분의 국경 실전 응용"*으로 표기한다(사상적 선행·메커닉 명시를 A7로 미루지 않는다). 구판 83화에서 전진 배치. 습득 논리 = **위기에서 필요가 발명한다** — 전면 소환은 대가도 낙인도 감당 불가한 자리에서만 나올 수 있는 해법.
- **정의(구판 원문 계승)**: 온전히 불러내는 대신 **서슬의 끝자락만 손끝으로 당긴다 — 부르는 게 아니라 빌리는 것**.
- **만능열쇠 방지**: ① 이 시점의 절제 소환은 **성공률·감량폭 미확정**(에반 본인도 확신 없음) ② 빌린 값도 값이라 감각이 되돌아오지 않는다 ③ A5~A6에서 재사용할 때마다 **실패 1회 이상**을 반드시 배치할 것(다음 아크 계약에 인계).

## §4 아크 진입/결착 상태

- **진입 상태(31화 시작 시)**: **아크브릿지에는 이미 22화부터 체류 중**이다(상부·하부 공방까지 겪었고, 이제 하부 심부·협곡 방면으로 처음 내려간다 — 재착지 아님). **무부채**(16화 완제)이며, 등을 미는 것은 갚을 날짜가 아니라 **신원 노출**이다 — 라인하르트라는 이름은 살아 있고 에반이라는 이름은 말소돼 있다. 소환은 여전히 '흑마술로 오해받는 역학', 나침반은 여전히 장부상 **'고장. 감정 불가'**. 소지 조각 = **나침반 1개**. **루미에르 아르카나는 동행이 아니라 연결**(30화 결착)이며 지금은 외지 의뢰로 공방을 비웠다 — 왕래는 도표·서신뿐. 세 손은 아직 전부 얼굴이 없고, **30화 두 번째 쪽지**『값은 잘 매겼네. 이제 자네 차례일세.』가 답 없이 남아 있다.
- **결착 상태(52화 종료 시)**: 조각은 **2개**(나침반 + 50화 견인 잔파편)이고 둘이 같은 방향으로 떤다 — **본 아크 이후 1장 내 추가 획득은 없다**(51화 제단의 다른 조각은 성국 회수조가 압수, 미획득). 장부의 '고장'은 **'방향'**으로 고쳐 적혔다. **절제 소환을 습득**했고(성공률·감량폭은 미확정), 그 값으로 감각 한 조각과 **성국 회수 장부의 한 줄**을 내줬다 — 신원 노출은 지울 수 없는 단계로 올라갔고 이것이 A5~A7의 압박 축이다. 세 손은 각각 그림자를 드리웠으되 얼굴을 준 것은 **사들이려는 손 하나뿐**(38화 '말끔한 얼굴'), 죽이려는 손은 하청과 별도 표지로만, 지켜보던 손은 무기척 흔적으로만 남았다. 세로축은 **확정이 아니라 공포로** 닫힌다 — 스물세 발자국은 있고 명단은 그보다 짧지만, **인과는 아직 아무도 확정하지 못했다**(62화 방명록으로 이관). 루미에르는 끝까지 동행하지 않았다 — 대면은 40화 한 번, 나머지는 도표와 맡긴 도구뿐. 방향은 둘로 갈렸다 — 발밑의 지하와, 저울 문양이 부르는 카르델라. **소환장 한 장이 53화 도입을 강제 개시한다.**
