
## B군 — 선택이 필요한 것 (PM 추천안 있음)

### B-1. 「소환 매개체」 용어 분리 *(원 2번)*

같은 낱말이 두 가지를 가리키고 있다. 집필자가 검색하면 섞여 나와 **에반의 매개체가 아닌 물건을 쥐여줄 위험**이 있다.

| | 무엇 | 사례 |
|---|---|---|
| ① | **에반식 매개체** — 죽은 자가 잠든 자리 | 무명의 이름표 |
| ② | 다른 소환사의 **시전 도구** | 두 번째 매장(강령 낫)·트라이클로(정령 마력핵) |

| 안 | 내용 | 비용 |
|---|---|---|
| **★ 개명** | ②를 **「시전 촉매(Casting Focus)」**로 바꾼다 | 4개 문서 수정 |
| 유지 | 그대로 두고 게이트에 경고만 | 낮음 · 위험 남음 |

### B-2. 파괴 규칙 개정 — 라케시스의 은사 · 해구의 자침 *(원 3번)*

둘 다 **「파괴 불가·손상 완전 면역」**이라 §1 원점 7항 3(매개체 파괴 = 영구 상실)이라는 최대 긴장 장치를 무력화한다.
※ 천공의 자침(파괴 시 소환 활성화)은 **존치 판정** — 한 번 쓰면 영영 잃는 일회용이라 원점을 오히려 강화한다.

| 안 | 내용 |
|---|---|
| **★ 조건부 파괴** | 「부술 수 없다」 → **「부수는 법을 아직 모른다」**. 전자는 규칙이고 후자는 미스터리다 |
| 예외 인정 | 두 개만 특별한 유물로 남긴다 |
| 원문 유지 | 무적 유물 2개를 그대로 둔다 |

### B-3. §1-G 종족 충돌 — 총 7건 *(원 1번 + §3-C 신규 5건)*

성장영웅은 전원 인간 또는 인간 혼혈인데, 문서가 순수 이종족으로 기술한 인물들.

| 인물 | 문서 기술 | 비고 |
|---|---|---|
| 루시엔 아르카나 | 에테르 엘프 | §3-B 배정됨(비상하는 매) |
| 엘리안 시르 | 하이 엘프 | §3-B 배정됨(사상 최강의 매니저) |
| 벨라시아 문 | 하이 엘프 | 신규 |
| 칼리안 드라코 | 용인족 | 신규 |
| 브론 스타하머 | 태고 드워프 | 신규 |
| 테일런 실브레이커 | 수인족 | 신규 |
| 카시엘라 트라이던 | 인어족/세이렌 | 신규 |

| 안 | 내용 |
|---|---|
| **★ 인간 혼혈로 보강** | 한쪽 핏줄을 인간으로. **그 혼혈 자체가 서사 자산이 된다**(양쪽에 못 낀 자) |
| 계열 이동 | 현존영웅으로 옮긴다 — 성장영웅에서 뺀다 |
| §1-G 예외 | 원점을 고쳐 이들만 예외로 |
| 개별 판정 | 7명을 각각 다르게 |

### B-4. 「재벌집 막내아들」 처리 *(신규 · PM 발명 검출건)*

원점 §1-K 모티브 풀에 없는데 PM이 프롬프트에 임의 투입했다. 그 모티브로 배정된 2명이 결재 전 무효 상태다.

| 안 | 내용 |
|---|---|
| 풀에 추가 | §1-K에 정식 등재하고 2건 유효화 |
| **★ 재배정** | 레오나르드 솔라리안·기네비어 라크루아를 §1-K 안의 다른 원전으로 |
| 보류 | 두 인물을 3차로 내린다 |

## C군 — 작가만 정할 수 있는 것 ★최대 병목

### C-1. 초반에 에반이 무엇을 쥐는가 *(원 5번)*

**이것이 1-A 구조의 입력값이다.** 정해지지 않으면 비트를 깔 수 없다.

**지금 고를 수 있는 재료:**

| 재료 | 규모 | 성격 |
|---|---|---|
| **짝짓기 40쌍** | 40 | 매개체 없던 소환영웅에 기존 아이템을 붙인 것. 영웅급·정예급(초반 구간) 중심 |
| **승격 후보 26건** | 26 | 「잊혀진 왕국」 유물군. 저무는 종·빛바랜 인장·마지막 매듭 등 |
| 기존 확정 55건 | 55 | 대부분 신화급·전설급 — **초반에는 못 쓴다** |

**정해야 할 것 3가지:**
1. **몇 개로 시작하나** — 에반이 1화 시점에 이미 몇을 부를 수 있나 (0개? 1개? 서넛?)
2. **1-A 안에서 몇을 얻나** — 40~60화 동안 짐이 몇 칸 느나
3. **첫 번째는 무엇인가** — 1화에서 쥐는 물건. 이게 작품의 첫인상이다

> [!tip] PM 의견
> **「잊혀진 왕국」 유물군**이 첫 번째로 적합해 보입니다. 작품 제목·§1-B(역사는 이긴 자의 역사)와 한 몸이고, 등급이 낮아 초반에 자연스럽습니다. 「빛바랜 인장 — 잊혀진 왕국의 마지막 인장반지, 감춘 혈통」 같은 것은 감정사 손에 들어올 법하면서 정치적으로도 위험합니다.
