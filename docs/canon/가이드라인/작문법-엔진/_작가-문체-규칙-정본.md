## 규칙 1. 사람을 가리킬 때는 이름을 쓴다 (표본 최다, ~55건)

소개가 끝난 인물은 **직업명·역할명·대명사로 되돌아가지 않는다.** 「노인/주인/견습생/남편/생선 장수/그/그 뒷모습」→ 전부 기명.

- `노파가 손끝으로 나침반을 쓰다듬었다.` → `말바가 손끝으로 나침반을 쓰다듬었다.`
- `주인이 어깨를 으쓱했다.` → `군터가 어깨를 으쓱했다.`
- `그 뒷모습이 완전히 어둠에 접힐 때까지` → `빌렘의 뒷모습이 어둠에 잠길 때까지`
- `아까 그쪽 어른도 예의를 아는 쪽이라고 하셨거든요.` → `아까 브란트도 자기들이 그나마 예의를 아는 쪽이라고 했거든요.`
- `노인이 이런 얼굴을 하는 건 처음 보았다.` → `도렌이 저런 얼굴을 하는 건 처음 보았다.`

**예외**: 정체 은닉 장치는 별칭 유지(「말끔한 얼굴」), 무명 유지 대상(갑주·자객 3인)은 기명 금지.

## 규칙 2. 문장을 계사(繫辭)로 닫지 않는다 (~45건)

「~것이었다 / ~셈이었다 / ~뜻이(기도)었다 / ~법이었다 / ~모양이었다 / ~참이었다」로 끝나는 논평 종결 → **동사로 끝나는 사실 서술**.

- `문틈으로 밀어 넣어진 것이었다.` → `문틈으로 누가 밀어 넣고 갔다.`
- `셈이 그렇게 맞아떨어지는 밤이었다.` → `그날 밤의 셈은 그렇게 맞았다.`
- `진품 여부에 빚쟁이 조합의 체면이 걸려 있었다는 뜻이기도 했다.` → `진품 여부에 조합의 체면이 걸렸으니 그럴 만도 했다.`
- `여자가 내놓을 조각은 이미 다 나온 참이었다.` → `여자가 내놓을 조각은 이미 다 나왔다.`
- `두 닢에 거래가 성사됐다.` → `두 닢을 건넸다.`

## 규칙 3. 한 문장에 사실 두 개를 쉼표로 잇지 않는다 (~40건)

쉼표+「~고,」로 붙은 두 사실은 **마침표로 끊고 뒤 문장에 주어를 세운다.** 200자 넘는 단락은 분절.

- `은에 청동을 섞은 흔한 세공, 문양은 상단 소속을 나타내는 물고기 무늬였다.` → `은에 청동을 섞은 흔한 세공이었다. 새겨진 물고기 무늬는 상단 소속을 나타냈다.`
- `나는 저울 눈금을 맞추는 척하며 잔금 숫자를 다시 헤아렸다. 셈은 몇 번을 다시 해도 줄어드는 법이 없었다.` → `…잔금을 다시 헤아렸다. 몇 번을 세어도 액수는 줄지 않았다.`
- `어젯밤에 장부에서 한 줄 봤습니다. 오늘 아침엔 지도에서 한 자리 봤고요.` → `어젯밤에는 장부에서 빈칸을 봤고, 오늘 아침에는 지도에서 사라진 자리를 봤습니다.`

## 규칙 4. 에반의 대사는 **존대 완결형 + 능청 어미**로 (~35건)

축약 반말투(`-어요`, `나/내가`)를 남기지 않는다. 종결은 `-습니다 / -까`, 여유는 어미로(`~거든요 / ~라서요 / ~모양이군요 / ~던데요`).

- `알아요. 방금 이마로 확인했어요.` → `압니다. 방금 이마로 직접 확인했거든요.`
- `내가 원래 흥정이 느린 사람이라.` → `제가 원래 흥정은 오래 끄는 편이라서요.`
- `조용하네. 혼나는구나.` → `대답이 없으시네. 혼나는 모양이군요.`
- `할아버지도 같이 가주면 안 돼요?` → `영감도 같이 가주시면 안 됩니까?`
- `주우면 임자라던데요.` → `먼저 손에 넣는 쪽이 임자라던데요.`

**격식 한자어는 반대로 내린다**: `그 할머니 성함이 어떻게 되십니까` → `그 할머니 이름이 뭡니까` / `영업은 해가 뜨고 나서` → `장사는 해가 뜬 뒤에` / `가담한 게 언제쯤인지는요` → `그 일에 들어간 게 언제쯤입니까`.

## 규칙 5. 서술에는 아포리즘·자문·자기정정을 쓰지 않는다 (~30건)

격언·일반론·「왜인지 나도 모르겠다」·「정확히는」 류 부연은 **전량 삭제하거나 대사(도렌·군터)로 넘긴다.** 에반의 서술은 관찰과 셈만 한다.

- `이런 밤이면 가끔 헤아려 본다. …읽히는 게 있어야 값도 매기는 법인데, 이건 텅 비어 있었다.` → (삭제) `죽은 자들이 남긴 잡동사니에 값을 매기고, 그 돈으로 하루치 빵값과 밀린 잔금을 메운다. 늘 그래왔다.`
- `손이 떨리고 있다는 걸 알았다. 금화 다섯 닢을 걷어찬 손이 왜 이제야 떠는지 나도 알 수 없었다.` → `금화 다섯 닢을 걷어찬 손은 사내가 떠난 뒤에야 흔들리기 시작했다.`
- `손을 뗐다. 정확히는, 떼려고 했더니 손이 이미 떨어져 있었다.` → `손을 떼려 했을 때는 이미 쇠테에서 떨어진 뒤였다.`
- `정보라기보단 예감에 가까웠지만, 이 노인의 예감은 여태 틀린 적이 없었다.` → `예감이든 정보든, 돈이 몰리는 곳만 맞으면 그만이었다.`

## 규칙 6. 같은 낱말을 인접 두 문장에 두 번 쓰지 않는다 (~25건)

특히 직전 문장에서 쓴 동사·명사. 한 낱말만 갈아 끼워 해소한다(구조는 손대지 않는다).

- `종이 자체가 뭔가를 말하려다 만 것 같은` → `아무것도 적히지 않은 종이가 무언가를 말하려다 멈춘 듯했다`
- `발소리는 사라졌는데, 흔적까지 사라진 건 아니었다.` → `발소리는 끊겼지만, 흔적까지 없어진 건 아니었다.`
- `숨죽인 어둠 속에서 그것이 정점을 찍었다. …` → 뒤 문장 `정점` → `압력이 절정에 닿은 순간`
- `종이는 그냥 종이였다. 종이 위에 앉은 문만 문이었다.` → `종이는 평범했다. 그 위에 들어앉은 문만 평범하지 않았다.`

---

## 규칙 7. 서술문 안의 줄표(—)는 마침표로 끊는다 (~15건)

대사 안의 말 끊김 줄표(`"그건 나도—"`)는 **유지**. 서술의 정의·부연 줄표만 제거.

- `노파, 초소, 폐광—낱말 하나하나는 별것 아닌데` → `노파, 초소, 폐광. 따로 놓으면 별것 아닌 말들이`
- `걸리는 건 마지막 줄이었다 — 오늘 낮 내 걸음까지 알고 있으니` → `걸리는 건 마지막 줄이었다. 오늘 낮 내 걸음까지 알고 있으니`
- `표식, 은화, 그리고—나침반.` → `표식과 은화, 그리고 나침반.`

---

## 규칙 8. 「A가 아니라 B」 대조 정의는 화당 1회까지 (~15건)

대조로 규정하지 말고 **B를 그대로 서술**한다.

- `문 앞에 선 어느 사내가 마지막으로 느낀 건 안도가 아니라 공포였다.` → `문 앞에 선 어느 사내의 마지막 감정은 공포였다.`
- `문 두드리는 예의 같은 건 챙기지 않은 빚쟁이가` → `문 두드리는 예의도 없이 들이닥친 빚쟁이가`
- `놀란 것도, 언짢은 것도 아닌—예상했던 답을 확인한 얼굴이었다.` → `놀라지도 언짢아하지도 않았다. 예상했던 답을 확인한 얼굴이었다.`

살려둔 1회 예: `목숨이 아니라 물건.`(8화) — 정보 자체가 대조일 때만.

## 규칙 9. 수동·무생물 주어를 능동 행위자로 (~12건)

- `문틈으로 밀어 넣어진 것이었다` → `누가 밀어 넣고 갔다`
- `그 소리가 밤공기를 타고 양쪽에 똑같이 닿았다.` → `벽돌 무너지는 소리가 밤공기를 타고 담 양쪽으로 퍼졌다.`
- `발끝에 닿는 물기가 개천에서 흘러든 것임을 알려줬다.` → `발끝에 차는 물기를 보니 개천에서 흘러든 배수로가 분명했다.`
- `그 방향만이 여전히 마음에 걸렸다.` → `나침반은 여전히 그곳으로 나를 잡아당겼다.`

## 규칙 10. 사람을 신체 환유로 세지 않는다 (~12건)

「손 / 입 / 얼굴 / 그림자」로 사람을 세는 표현은 **세력 프레임(‘세 손’)에만** 남기고, 개별 인물·인원수는 「자 / 사람 / 셋」으로.

- `이 골목 빚을 훑고 다니는 얼굴이라` → `이 골목의 빚을 훑고 다니는 자라`
- `칼 든 손은 적어도 뭘 원하는지 소리 내어 말한다.` → `칼 든 자는 적어도 원하는 걸 입 밖으로 냈다.`
- `그 얘기를 하던 입들이 하나둘 조용해진 거지.` → `그 얘기를 하던 자들이 하나둘 입을 닫은 거지.`
- `그럼 순순히 넘기면 저 그림자 셋이 좀 줄어드나요?` → `순순히 넘기면 저 셋은 물러납니까?`
- `부수적인 화물치고, 숫자를 꽤 채워 왔네요.` → `부수적인 화물치고, 사람을 꽤 많이 데려왔네요.`

---

## 규칙 11. 명사 연쇄에는 「의」를 넣거나 붙여 쓴다 (~12건)

- `이 골목 빚을` → `이 골목의 빚을` / `손님 소매를` → `손님의 소매를`
- `그쪽 상단 놈들 씀씀이` → `그쪽 상단 놈들의 씀씀이` / `브란트 님 표식` → `브란트 님의 표식`
- `물건 값은 저한테 받으시죠` → `물건값은 저한테 받으시죠` (값·삯 합성어는 붙여 쓴다: 물건값·추억값·감정료)
- `자루를 쥐는 순간` → `칼자루를 쥐는 순간`

---

## 규칙 12. 나침반은 「가리키지」 않고 「잡아당긴다」 — 목적어를 명시한다 (~10건)

당기는 대상(손목/몸/가슴)을 반드시 쓴다. 감각 표지는 화당 1회(화말 훅 우선).

- `바늘도 없는 몸통인데, 가리키던 방향만은 눈을 감아도 지워지지 않았다` → `바늘은 망가졌는데도, 그것이 잡아당기던 방향만은 눈을 감아도 지워지지 않았다`
- `바늘 없는 방향으로 무언가 실처럼 팽팽하게 당기는 감각이 손목을 타고 올라왔다` → `망가진 바늘과는 상관없는 쪽에서, 무언가 실처럼 팽팽하게 손목을 잡아당겼다`
- `품속 쇳조각이 걸음마다 손끝을 당겼다` → `품속의 쇳조각이 걸음마다 몸을 잡아당겼다`
- `나침반이 방향을 잃고 반대로 당기기 시작했다` → `코트 안의 나침반이 갑자기 반대쪽으로 당겼다`

---

## 규칙 13. 감정 형용을 즉물 동작으로 바꾼다 (~10건)

「쓸쓸한 웃음이었다」류 라벨 금지. **손이 무엇을 했는지** 쓴다.

- `노파가 잠깐 웃었다. 쓸쓸한 웃음이었다.` → `말바가 보퉁이 자락을 손끝으로 접었다 폈다. 웃는 입가만 남고 눈은 웃지 않았다.`
- `고맙다는 말 대신 반지 낀 손을 가슴께에 가만히 붙였다 뗐다.` → `고맙다는 말 대신 반지 낀 손을 가슴께에 잠시 얹었다.`
- `남편이 낡은 회중시계를 내미는데, 내미는 손보다 거두려는 손이 더 빨라 보였다.` → `하셀은 낡은 회중시계를 내밀면서도, 당장이라도 거둬갈 듯 손에 힘을 주고 있었다.`

---

## 규칙 14. 서술의 「뭔가」는 「무언가」, 대사의 「뭔가」는 그대로

- 서술: `종이 자체가 뭔가를 말하려다` → `무언가를 말하려다` / `안에서 뭔가 살아 있는 건` (대사·문서 인용은 유지)
- 대사: `가서 뭐가 우는지 확인이나 하고 오게.` — 유지.

같은 원리로 서술의 「근데」·「~치고는」 축약은 유지 가능하나, 서술 종결부의 구어 축약(`~걸`, `~잖나`)은 대사 전용.

## 규칙 15. 지시어(그/이/저 + 명사, 그것)는 구체 명사로 되돌린다

- `이건 안 파실 물건 아닙니까.` → `이건 팔 물건이 아닙니다.`
- `그 소리가` → `벽돌 무너지는 소리가`
- `형체는 정면 하나만 보고 서 있었다` → `갑주는 정면 하나만 보고 서 있었다` (단, 직전 문장이 이미 「갑주」면 다시 `저것이`로 — 규칙 6 우선)
- `그건 자네 사정이지 내 사정인가.` — 대사의 지시어는 유지.

---

## 규칙 16. 화말 마지막 문장은 짧은 감각·행동 이미지로 끝낸다

접속 도입(`그리고 그때`)을 지우고, 훅 이미지를 **문단 맨 끝으로** 밀어낸다. 순서 교체만으로 해결되면 어휘는 손대지 않는다.

- 6화: `…얼룩이 번지는 속도가 조금씩 빨라지고 있었다.` → `…얼룩은 조금씩 더 빠르게 번지고 있었다. 누군가 다시 글자를 채워 넣는 것처럼.`
- 8화: `그리고 그때, 담 너머에서도 발소리가 들려오기 시작했다.` → `그 순간, 담 너머에서도 발소리가 가까워지기 시작했다.`
- 1화: `그 방향만이 여전히 마음에 걸렸다. 다른 어디로도 아니고, 딱 그쪽으로만—…` → `나침반은 여전히 그곳으로 나를 잡아당겼다. 폐광 너머, 이 도시 누구도 발 디딘 적 없다는 지하로.`

## 규칙 17. 독백(' ')은 추측 의문형이 아니라 단정 관찰로

- `'설마, 저 노파도 뭔가에 쫓기고 있었던 건가.'` → `'저 눈빛은, 나침반을 두고 가는 사람의 눈빛이 아니었다.'`
- 다만 **자기 다짐 반말 독백은 관행으로 유지**: `"내가 직접 가서 확인한다. 그게 무엇이든."`(10화 #92 유지 판정)

---

## 규칙 18. 수치·기한은 막연하게 굴리지 말고 셈으로 적는다

앵커 수치(두 닢·여덟 닢·이레)는 **불변**, 표현만 셈이 되게.

- `잔금의 셋에 하나쯤은 메울 액수였다` → `열이틀 안에 갚아야 할 잔금의 삼분의 일쯤을 메울 액수였다`
- `빚 기한은 하루하루 줄어드는 중이었다` → `빚을 갚을 날은 하루씩 가까워졌다`
- `여드레도 그냥 흘러가 버릴 날일 뿐이었다` → `여드레 중 하루가 허무하게 사라질 뿐이었다`

## 규칙 19. 대사 사이에 동작이 끼면 행을 나눈다 (1·3화 집중, ~30건)

한 단락에 「대사 → 동작 서술 → 대사」가 샌드위치로 들어가면 **각각 독립 행**으로. 짧은 응수 주고받기는 인라인 허용(4~10화 관행).

- `"칼은 좀 치워주시겠습니까." 나는 손을 내밀었다. "물건이 상하면 감정도 못 하니까요."`
  → `"칼은 좀 치워주시겠습니까."` / `나는 손을 내밀었다.` / `"물건이 상하면 감정도 못 하니까요."`
- `"밀랍만 봐도 알겠어. …" 노인이 종이를 뒤집어 빛에 비췄다. "이 동네에 무허가 종이 장수는 딱 하나 남았지…"` → 3행 분절

# 작가가 살려둔 것 — 유지 목록 (건드리지 말 것)

1. **시그니처 대사**: 「가짜에는 죽은 자가 없습니다」 / 「이 물건 값은 내가 매깁니다」 / 「에누리 없음, 외상 사절」 / 「정에 값을 매기는 게 제 일이 아니라서요」 / 「추억값은 안 쳐드립니다」 — 표제 조응 문장은 리뷰에서도 **유지 판정**(4화 #24).
2. **초단문 컷**: `문이었다.` `백지였다.` `비어 있었다.` `형제였다.` `손이 먼저였다.` `문은 열리지 않았다.` `물어볼 사람은 없었다.` `읽혔다. 짧고 날카롭게.` — 전건 무손상.
3. **문두 말줄임 「…」**: 유지되고 오히려 강화됨(`"…얼굴이 안 그려지는군"` → `"……얼굴이 떠오르질 않는군"`). 화말 발화 `"…뒤."`는 무손상 명시.
4. **대사 안 줄표(말 끊김)**: `"그건 나도—"`, `"당신, 대체 뭘 봤길래—"`, `"뭐야, 누가 담을 부수—"`.
5. **노인·이웃의 격언조 대사**: `"공짜로 얻는 힘은 없다는 건 옛이야기가 아니라 장사치 셈법이지."` — 아포리즘은 **대사에서만** 허용.
6. **능청 응수·자기비하 유머**: `"용병단은 술값이 안 나와서요."` `"두통은 팔 데가 없어서 그냥 참죠."` `"눈으로만 사두죠. 보는 건 외상도 안 되잖습니까."` `말해놓고 조금 민망했다.`
7. **장부 3항 나열 리듬**: `훈장, 나침반, 독촉장.` / 명사문 3연(5화 #9 유지 판정), 반복 셈 문체(5화 #64 유지 판정).
8. **감정 전문어 앵커**: 잔재 / 저림 / 값을 매기다 / 삯 / 임자 / 셈 — 치환 금지(단 저림의 *결*은 물건별로 변주: `뻣뻣하고 무거운 결`).
9. **표기**: 문패·의뢰장·쪽지는 「」로 통일(『』 사용 금지, 10화 #102).
10. **은닉 별칭**: 「말끔한 얼굴」, 무명 유지(갑주·자객 3인) — 기명 금지.

# 집필 전 자기검사 12줄 (초고 제출 전 훑기)

1. 소개된 인물을 직업명·대명사로 되부른 곳이 있나 → 이름으로
2. 「~것이었다/셈이었다/뜻이었다」로 끝난 문장 몇 개인가 → 0을 목표
3. 쉼표로 이어붙인 두-사실 문장 → 마침표로 끊고 주어 세우기
4. 에반 대사에 `-어요` 축약·`나/내가`가 남았나 → `-습니다`·`저/제가`
5. 서술에 격언·자문·「정확히는」이 있나 → 삭제 또는 대사로 이동
6. 인접 두 문장에 같은 낱말 → 한 낱말만 변주
7. 서술문 줄표(—) → 마침표
8. 「A가 아니라 B」 화당 1회 초과 → B만 서술
9. 나침반 서술에 목적어(손목/몸/가슴)가 있나, 감각 표지 화당 1회인가
10. 사람을 손·입·얼굴로 셌나 → 자/사람/셋 (‘세 손’ 세력 프레임만 예외)
11. 서술의 「뭔가」 → 「무언가」 / 명사 연쇄 → 「의」 또는 붙여쓰기
12. 마지막 문장이 짧은 감각·행동 이미지로 끝나는가, 「그리고 그때」로 시작하지 않는가
